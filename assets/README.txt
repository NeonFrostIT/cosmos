СВОИ КАРТИНКИ ДЛЯ ORBIT QUEST

Положи сюда файлы PNG (лучше прозрачный фон):

scientist.png  — учёный (один персонаж, статичный PNG)
astronaut.png  — космонавт (один персонаж, статичный PNG)
rocket.png     — ракета (одна ракета, статичный PNG)

Дополнительно:
crystal.png    — одинаковый вид двух кристаллов
background.png — единый полупрозрачный космический фон (необязательно)

Рекомендуемые размеры: персонажи 400x500 PNG, ракета 400x650.
Размеры автоматически подгоняются; анимации движения создаются кодом.
Не переименовывай файлы. Если картинки нет, игра покажет нарисованный объект.
После замены обнови игру Ctrl+F5, чтобы браузер загрузил новый файл.
